# Changelog

This file keeps a plain-English history of notable changes to this project. It follows the
[Keep a Changelog](https://keepachangelog.com/) style, and it updates itself: a git hook at
`.githooks/post-commit` reads each new commit and, if the commit message is written in the
conventional format (`type(scope): description`, for example `feat: add dark mode`),
automatically adds a dated bullet line to the right section below and commits that update
on its own. Commits that aren't written in that format (including this repo's routine
"Reflect build" commits) are simply skipped: nothing is logged for them, and nothing breaks.
